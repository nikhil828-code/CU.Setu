# 🌐 CU.Setu – Bridging Students, Connecting Possibilities.

### A University Student Networking & Collaboration Platform

CU.Setu is a student networking platform designed to bring university students together through meaningful connections, technical collaboration, project sharing and knowledge exchange.

Inspired by professional networking platforms, CU.Setu creates a digital space where students can showcase their technical skills, discover talented peers, share innovative ideas and collaborate on projects.

Built using Python and Data Structures & Algorithms, the platform combines real-world social networking functionality with practical applications of core computer science concepts.

---

## 🚀 Project Overview

CU.Setu aims to transform the way university students connect and collaborate.

Students can create profiles, build professional networks, share technical projects, discover like-minded individuals and find suitable teammates for collaborative opportunities.

The platform models student relationships as a graph, allowing algorithms such as Breadth First Search (BFS) to calculate connection paths and discover relationships within the university network.

## 🧩 DSA Implementation

CU.Setu demonstrates the practical application of Data Structures and Algorithms in a real-world student networking environment.

| Functionality | Data Structure / Algorithm |
|---|---|
| Student network | Graph |
| Accepted connections | Adjacency List |
| Shortest connection path | BFS |
| Mutual connections | Set Intersection |
| Student recommendations | Graph-based ranking |
| Recommendation ordering | Heap / Priority Queue |
| Username prefix search | Trie |
| User lookup | Hash Table |
| Skill frequency | Hash Map |
| Feed organization | Heap / Priority Queue |

The core objective is to ensure that DSA concepts are implemented in Python and are responsible for the actual application logic.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd CU.Setu
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows:

```bash
venv\Scripts\activate
```

Linux / macOS:

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
